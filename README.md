# 逃离夜校

[English README](README.en.md) · [共同开发与二创](CONTRIBUTING.md) · [MIT 许可证](LICENSE) · [免责声明](DISCLAIMER.md) · [在线游玩](http://154.217.245.217:4100/) · [客户端下载](http://154.217.245.217:4100/downloads/)

《逃离夜校》是一款 1～4 人合作的第一人称校园恐怖游戏。玩家要在午夜校园中寻找线索、躲避值周生、互相救援，并完成八个章节后离开校门。游戏保留原有的代码绘制非写实粉笔黑板风格，网页端、桌面端和 Android 客户端共享同一套关卡与联机协议。

## 本地开发

需要 Node.js 22.18 或更高版本。网页游戏和服务器位于 `game/`：

```sh
cd game
npm ci
npm run dev       # 构建客户端并启动本地服务器
npm run check     # 类型检查、单元测试、生产构建和浏览器回归
```

生产服务可用 `npm run build` 构建，再用 `PORT=4100 npm start` 启动。服务器通过 HTTP 提供静态页面，并在 `/ws` 提供 WebSocket 联机。

## 桌面与 Android 打包

原生壳位于 `apps/`。完整步骤见 [`apps/README.zh-CN.md`](apps/README.zh-CN.md) 和 [`docs/build-native.md`](docs/build-native.md)。基本流程如下：

```sh
cd apps
npm ci
npm run icons
GAME_ROOT=/path/to/escape/game npm run prepare:game
npm test
npm run desktop:mac   # macOS DMG
npm run desktop:win   # Windows NSIS 安装器
```

Android 需要 Android SDK 35、JDK 17 和 Gradle 8.11.1，在 `apps/android` 执行 `gradle assembleRelease`。签名信息只从环境变量读取，不应写进仓库。
