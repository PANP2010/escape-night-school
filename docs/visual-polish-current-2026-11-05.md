本轮基于 `fb7e154`，把审查后的旧 graphics 增量移植到当前版本，并重新完成真实浏览器基线、迭代和验收。生产文件为 `campus/scene.ts`、`textures.ts`、`style.css`；不包含角色、音频、输入行为、服务器或关卡专属机制。

A/B 楼采用共享 256² 数据纹理，在世界坐标中给灰泥、潮痕、水磨石分缝/细粒、桌椅木纹一致的米制尺度，近处细节随像素足迹淡出。荧光灯获得柔和冷色灯池和低强度粗糙地面反射，反射跟随死灯/跳闸/断电状态，保留原有夜间暗适应。真实截图后进一步把潮痕 0.18→0.12、木纹对比 0.38→0.28，减少条纹抢眼。

室外使用低亮度天空层次，树冠散射跟随实际光照，修正夜间自发亮。门口与露天天井统一外景、天空和视距判断；深室内正确裁掉分块外景，避免薄楼无法识别室内。只保留时钟动态 position/normal 数据，修复渲染上传后切换时钟可能写入 null 的问题。额外几何为两批随楼层显示的少量折纸和一个天空球，没有后处理、影子贴图或新增灯。

HUD 保留深绿黑板与粉笔色，常驻信息改为薄线和轻底，降低厚木框、噪点与发光文字的存在感。房间信息收为小型状态条，目标/物品/教程区分层级，教程上移、减少横向遮挡。手机操作保留52 px动作按钮、44 px地图/聊天点击区域，静态摇杆降对比；667×375的L3完整线索已实测避开耐力条。更新通知现有行为保留且回归通过。
