# 0.6.0 安装版与局域网联机

Windows、macOS 安装版内置完整游戏服务，Android 安装版内置游戏画面与资源，通过网络连接电脑房主或云端服务。

## 同一 Wi-Fi 一起玩

1. 房主在 Windows 或 macOS 启动界面点击「局域网开房」。
2. 复制「朋友加入地址」，例如 `http://192.168.1.100:52996`。地址中的端口每次开房可能不同，请完整复制。
3. 房主点击「房主进入校园」，输入名字并创建房间，把房间码告诉朋友。
4. 朋友在浏览器打开分享地址；也可在桌面版「联机服务器」或 Android 的服务器地址中填写该地址，再加入相同房间码。

设备须处于同一局域网。电脑同时显示多个地址时，选择与朋友设备同一网段的地址。手机不要填写房主的 `127.0.0.1` 地址；它在手机上代表手机自己。若无法连接，检查系统的局域网访问权限、防火墙与 Wi-Fi 的设备隔离设置。

关闭房主游戏窗口或退出应用会停止局域网服务。重新开房后，请重新分享显示的地址。

## 离线与云端

桌面版「本地游玩」无需网络，内置服务仅监听 `127.0.0.1`。Android 仍需要电脑房主或云端服务器，不含 Android 离线服务。

「在线组队」默认连接 `http://154.217.245.217:4100`。房间、速通榜属于当前连接的服务器；本地房主的榜单保存在应用用户数据目录，安装目录不会被写入。应用更新保留该数据目录。

## 本次验证

游戏运行时来源为 `bf75ab854e12df9b1423a72658202fc538cf5908`，准备时源码无未提交修改。macOS 两架构 DMG 均通过镜像完整性和应用严格递归签名检查。

Apple Silicon 的正式安装包已实际启动，验证真实局域网 IPv4 地址上的健康检查、0.6.0 版本、两条独立 WebSocket 创建并加入同一房间、开始游戏及持续快照、地址复制、关闭窗口停止服务，以及单人模式对局域网地址不可访问。页面错误为零。桌面和 Android 启动界面使用纯 CSS 与内联 SVG 绘制的非写实绿色粉笔黑板，应用人像仅用于图标。

Intel Mac 尚未在对应硬件运行。macOS 使用临时签名，未做 Developer ID 签名与公证。Windows 和 Android 的对应构建、签名与平台运行边界见统一发布目录中的平台验证记录；上述 Mac 验证不代表 Android 实机验证。

可复验命令：在准备好的 `apps` 目录执行 `node scripts/smoke-lan.mjs --executable <安装版应用可执行文件>` 和 `node scripts/smoke-launcher.mjs --executable <安装版应用可执行文件>`。报告与截图输出至该工作区的 `apps/output/`，不会覆盖旧发布包。
