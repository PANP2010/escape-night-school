# 逃离夜校 · 美术基准（art direction）

## 1. 调色板（style.css:3、:189）
| token | 值 | 含义 |
|---|---|---|
| --chalk | #e8e4d8 | 粉笔白：正文、图标；加 33–66 透明度做细线 |
| 次要文字 | #c9c4b4 | 说明、倒计时标签、图例 |
| --emerg | #4fd08a | 应急绿：安全、完成、圈内、引导 |
| 琥珀 | #e8c15a | 提醒：下一圈外、将要变化（只表示“注意”，不表示“危险”） |
| --warn | #ff5a4a | 警示红：圈外、锁着、淘汰倒计时 |
| --slate | --dust 4.5% 白噪点 + linear-gradient(155deg, #172820eb, #0b1513e6) | 黑板面：HUD 卡片底色 |
| --frame | 0 0 0 1px #d5dfc92e, 0 4px 18px #0005 | 卡片外框（代替实线边框） |
| 圈外雾 | rgba(52,10,46,.38–.9) 紫黑 + 爬动噪点 | “被熄灯吞没” |

规则：颜色只表达状态，不做装饰；同一含义全局同色。红只用于危险，绿只用于安全／完成。
状态卡用左侧 2–3px 色条标明状态（#objective、#zone-hud），正文仍为粉笔白。

## 2. HUD 版式
- 字号：正文 13–16px，最小 12px（手机地图图例 11px 是例外）；letter-spacing 1px；text-shadow 0 1px 2px #000a。
- 圆角 3px；卡片内边距 6–11px；相邻元素至少留 4px 空隙（e2e 用这个值断言）。
- 触控目标 ≥ 44×44px（地图／聊天按钮、地图内按钮、大厅主操作）。
- 固定槽位（基准视口：桌面 1280×720、手机 844×390）：
  - 左上：设置 → 房间条 #room-code（桌面 max-width 100vw−390px，给右上槽位留位）→ 线索本 → 房主行。
  - 右上：任务卡 #objective。大逃杀隐藏任务卡，由安全区卡 #zone-hud 接管同一槽位（手机在地图／聊天按钮下方，top 60px）。
  - 右下：体力条、手电电量；手机右下是动作键阵，左下是摇杆。
  - 中央：准星、交互提示、教学条 #tut（top 21–23%）。
  - 地图：桌面居中、手机夹在摇杆与动作键之间；不得盖住上面各槽位的信息。
- 新 HUD 先找槽位，不开新浮层；不能靠提高 z-index 压住别的信息。

## 3. 光照与雾
- 夜景基调：冷蓝黑环境，手电为主光源；恐怖感来自“近处看得清、远处看不清”，靠雾和剪影，不靠全局压暗。
- 可读性底线（用户 2026-10-28）：最暗的 L2 也要看清脚底的路。
- 大逃杀夜景量化（a2b-royale-hud.spec.ts，R13-2）：地面带（下 40%、中 70%）平均 luma 16–60，整帧 < 80，纯白像素 < 1%，地面比天空亮 ≥ 6。
- 近墙手电不得洗成大片纯白（R13-6，待做）。

## 4. 材质与模型
- 低模 + 手绘感：平涂色块，噪点纹理与 --dust 同源，不追写实高光。
- 视高 1.63 m（测试机位）；其余比例以现有模型为准，改动前先量再写进本页。

## 5. 动效节奏
- 入场：教学条 sub-in .4s ease-out；任务卡 obj-in .5s ease-out。
- 危险脉冲：1s ease-in-out（圈外卡片红光），只用于需要立刻处理的状态。
- 圈外雾：进入 0.25 s 收紧，离开 0.9 s 散开（“回圈像呼气”）。
- prefers-reduced-motion：关闭所有循环动画。

## 6. 验收方法
- 改前／改后同机位截图存 loop-codex/shots/<任务>-before|after.png，亲自 Read。
- 动起来才看得出的效果录 10–20 s 视频，交 tools/gemini 评分。
- 版式改动：e2e 量实际矩形（间距 ≥ 4px），再用 elementsFromPoint 检查文字上方最先绘制的元素，确认没被遮挡。
