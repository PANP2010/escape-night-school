# 0.6.2 安装版、局域网与最终验收

Windows 和 macOS 内置完整游戏服务，可离线单人或在同一局域网开房。Android 内置客户端资源，通过网络连接电脑房主或云端服务，不包含 Android 离线服务器。

## 同一 Wi-Fi 一起玩

1. 电脑房主打开「局域网开房」，复制应用显示的「朋友加入地址」。
2. 房主点击「房主进入校园」，输入名字并创建房间，将房间码告诉朋友。
3. 朋友用浏览器打开分享地址；也可在桌面版「联机服务器」或 Android 服务器输入框填写该地址，然后加入相同房间码。

请完整复制地址中的端口，每次开房可能不同。手机不要填写 `127.0.0.1`，它代表手机本身。多个网络地址时选择与朋友同一网段的地址。设备须处于同一局域网；连接失败时检查系统局域网权限、防火墙和 Wi-Fi 设备隔离。

关闭房主游戏窗口或退出应用会结束该服务；重新开房后请重新分享地址。桌面「本地游玩」仅监听本机，适合离线单人。

## 本次修复

恢复角色074原版的外形、身高比例、脸谱、眼镜和挎包，保留环境补光。第七关玩家、同伴倒影及镜中值周生使用原来的学生和无脸值周生模型。界面继续使用代码绘制的非写实粉笔黑板风。

值周生默认匿名。完整通关「无人生还」后，可以在创建下一个房间前主动开启人名彩蛋；默认关闭，建房后固定。只有开启后随机抽中「值周代号025」，才会出现粉笔圈与点名扫线 Boss。开发房、作弊跳关和章节预览不会解锁该功能。

网络重连成功后会清除大厅残留的旧断线提示；真正断线时仍暂停操作并恢复连接。

重开过场中的成员变化不会重复加载同一轮关卡或提前恢复环境声。配电箱的最终指引标记与瞄准范围和可见柜体对齐，电脑瞄准或手机点按柜体都可插入保险丝。

保留安装版鼠标视角、Esc 后重新捕获、统一设置和可关闭的物品高亮。香水使用淡黄色飘动粒子，在桌面、触控和低画质下均保留，不显示实时文字接近警报。抓住时有近脸跳吓、单次音效和倒地表现。

修复手机横屏中新版提示、线索本与目标卡的遮挡，并保留低画质下靠近时更密的香水粒子。

第一章开场朝向目标楼梯；第三章只有真正向西跨过回环线才传送。篮球碰撞声会引起敌人调查；角色074持续看见玩家时不会因为追逐时限突然停止。

创建前可以选择目标指引。开启指引、开发者房间或使用调试的整局不进入速通榜；旧规则记录保留归档。昵称 `DEV-LOCAL#` 创建专用私密开发房，可使用跳关、免抓和召唤等测试工具。

## 发布验收与复验

网页、服务端与五份安装包使用同一份冻结源码构建。发布附件 `release-manifest.json` 记录源码提交、各包字节数与 SHA-256；`release-validation.json` 及平台验证报告记录本版实际执行的检查和设备范围。

游戏验收包括类型检查、完整单元测试、生产构建和浏览器回归；桌面成品另验证单人、局域网、云端连接、鼠标操作及房主关闭后的服务退出。Windows 和 Android 执行构建、包体、资源与签名核验；Intel Mac 执行安装映像、包体与签名核验。相应报告明确区分包体验证与实机运行，不把静态检查记作实机测试。

macOS 使用临时签名，未做 Developer ID 签名与公证；Windows 未做商业签名。Android 延续原发布证书，以支持覆盖升级。原生包均包含 MIT 许可、中文许可说明、免责声明和第三方许可说明。

开发者可在 `game/` 执行 `npm run check`；在 `apps/` 执行 `npm test`。桌面成品可用 `node scripts/smoke-game-controls.mjs --executable <成品可执行文件>` 复验，加 `--mode lan` 验证局域网中的鼠标操作；完整房主流程使用 `node scripts/smoke-lan.mjs --executable <成品可执行文件>`。

开发与二创见[中文共同开发指南](../CONTRIBUTING.md)和[English contribution guide](../CONTRIBUTING.en.md)。欢迎 Fork、二创和商业使用，按 MIT 保留版权与许可。
