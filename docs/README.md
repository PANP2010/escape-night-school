# 逃离夜校 · 游玩指南

晚自习结束后，校园的门锁上了。独自寻找出口，或与最多三名同学组队，穿过八个章节，最后从校门外离开。

## 开始游戏

1. 打开游戏，输入自己的昵称。
2. 选择难度与是否开启目标指引，再创建教室或快速加入；也可输入朋友的四位房间码。
3. 房主等队友到齐后开始。一个人也能完成全部章节。

桌面安装版可选“本地游玩”，也可填写服务器地址在线组队。Android 版需要连接游戏服务器；可在封面设置服务器地址。一起玩的设备需要连接同一个服务器。

指引会显示目标箭头和地图上的出口、路线等标记。开启指引的整局不计速通排行；关闭指引的房间整局无法重新开启导航。快速加入匹配同难度、同指引设置的等待房。环境线索和物品高亮仍按原玩法与个人设置使用。

昵称 `DEV-LOCAL#` 创建专用私密开发房，可使用跳关、免抓、传送、钥匙、停电与敌人召唤工具。开发房全员整局不计排行，普通房不会因改名获得作弊权限。开发者可在第五关点击「召唤值周代号025（测试）」验证技能。正常房间的值周生默认匿名；完整通关「无人生还」后，可在创建下一局前主动开启人名彩蛋，开启后只有随机抽中「值周代号025」才触发 Boss。开发房和作弊跳关不会解锁人名彩蛋。

源码运行与各平台安装包的构建方式见 [源码与安装包重建](build-native.md)。

## 电脑操作

进入场景后，单击画面控制视角。按 `Esc` 释放鼠标。

| 操作 | 按键 |
| --- | --- |
| 移动 / 转头 | `W A S D` / 鼠标 |
| 跑步 | 按住 `Shift`，留意体力 |
| 蹲行 | 按住 `C` 或左 `Ctrl` |
| 开门、拾取、查看、躲藏 / 离开藏身处 | 靠近并对准目标，按 `E` |
| 搀扶倒地队友 | 靠近并对准队友，持续按住 `E` 三秒 |
| 开关手电 / 更换电池 | `F` / `R` |
| 目标引导 / 平面地图 | `G` / `M` |
| 标记准星位置 | `Q` |
| 查看队伍 | 按住 `Tab` |
| 线索本 / 操作提示 | `J` / `H` |

门和物品需要走近才能互动。被桌面、墙壁或关闭的门挡住时，请换一个位置。屏幕上的互动提示会告诉你当前对准的目标。

## 手机操作

建议横屏游玩。左侧拖动走路，右侧滑动转头；在场景中直接点门、钥匙、开关等物体即可互动。滑动用于转头，轻点用于操作。

右侧按钮控制手电、蹲行、跑步和换电池。屏幕上的“地图”“队伍”“标记”和线索本按钮可直接点按；开启指引的房间可在地图内切换目标箭头。靠近倒地队友后，长按队友持续搀扶，保持三秒。躲藏后按互动提示离开。

## 生存与组队

跑步会消耗体力并发出更大的脚步声；蹲行更安静。手电需要电量，背包有电池时可补充自己的手电。钥匙和多数解谜物品由全队共享，拾取后不必让每个人重复寻找。

看见淡黄色飘动的香水粒子，说明角色074就在附近。关灯、转角和藏身处都能帮助你避开他，但不要当着他的面进入同一个柜子。留意声音、门口和身后的走廊。

值周生只有在被有效注视时才会停住；墙壁挡住视线后，盯着他的方向也无法让他停下。转头寻找东西时，给自己留出距离。默认显示「值周生」，黑板使用匿名值日标记；解锁并主动开启人名彩蛋后，才会从姓名池随机抽取，击倒提示与角色显示一致，同一块黑板不重复。

被抓后会在原地倒地。有仍能行动的队友时，救援窗口为三十秒；队友靠近并持续搀扶三秒即可扶起。躲藏中的队友仍能出来救人，暂时断线且仍保留席位的队友也计入这一窗口。独自被抓或全队已无人能救时，会立即淘汰，普通章节随即重开；真正重开后才回到出生点。终章已有队友离校时，按本轮结果结算。

出局后可观察队友，电脑按 `Tab` 切换视角，下关重新参战。若房间允许中途加入，新成员先观察，本关结束后再一起行动。普通章节解开谜题后，尚未出局的队员还需要到出口集合；第三关的循环进度需要每个人自己完成。

## 八章路线

### 第一章：一楼·晚自习后

在教学楼 A 的一楼教室寻找有齿的抽屉钥匙，再打开上锁的讲台抽屉，拿到楼梯钥匙。无齿仿制钥匙是戏剧道具。普通门钥匙用于对应的锁门，不能代替楼梯钥匙。拿到楼梯钥匙后，到西南角楼梯间集合。

### 第二章：二楼·停电

在教学楼 B 二楼找到三枚保险丝，装入走廊中段墙上的保险盒，恢复出口门禁。搜索讲台时留意值周生；看住他再安排移动。恢复供电后，到西侧出口集合。

### 第三章：三楼·无尽走廊

先读走廊里的粉笔线索，按提示顺序进入教室，再回到走廊。只打开门不会计入进度，要真正走进去；走错门会重置自己的顺序。门序未解开时，沿走廊向西越过尽头的粉笔线会回到起点，已经完成的门序会保留；从 301 西门正常返回走廊不会触发回环。每名队员都需要亲自打破循环，再到西端绿色出口等人。

### 第四章：广播站

寻找四张编号贴纸：①②在三楼，③④在四楼。靠近并阅读后，全队共享记录；集齐后到四楼广播室，按贴纸编号顺序输入数字，停止广播，再回三楼东侧楼梯口集合。

目标箭头会选择最近的可达未读贴纸，显示编号与楼层；读齐后改指广播台，停播后改指出口。距离包含实际走廊和楼梯路线。听到点名时，尽快进入屏蔽柜或隔间；站在柜子旁边不等于已躲好，请确认屏幕已进入躲藏状态。

### 第五章：体育馆

四个开关分别在器材室、西侧篮架、北侧看台和记分台。需要让四盏灯同时亮起：单人每次点亮保持二十秒，多人保持五秒，组队时提前分工。器材室可能滚出篮球，撞到会短暂绊倒；场内还有值周生。四灯同时亮绿后，在东门内集合。

### 第六章：考场

四楼公告提供前三题线索，五楼公告提供后两题线索。考卷在四楼高三（7）班讲台，全队共用一份答案；查看线索后回讲台交卷。五题全部正确才会开启五楼西南出口，答错会引发十秒熄灯。四、五楼之间可以往返，出口在五楼。

### 第七章：镜廊

观察镜子寻找现实中看不见的线索。镜中倒影有延迟，原地停留太久也会招来危险。绕到守卫背后，抓住口袋可互动的时机取钥匙；直接盯着守卫时不能取。

一、二楼各有一处镜中门。用镜子判断它在现实墙上的对应位置，再去推开那面墙。两处密门都打开后，到二楼标本室外走廊集合。

### 第八章：教务处·点名册

在教务处找到点名册，划掉本轮自己的名字；队员都完成后会开始追逐。沿引导从办公楼正门撤离，绕过旗台，一路跑出校门，到门外安全区才算离校。站在校门里面不会完成。

已经离校的队员保留完成状态；还在校园里的队员仍须逃出或等待本轮结算。结果页会显示总用时、倒地次数和成员的离校状态。

## 遇到问题

- 看不到出口：先查看当前目标是否完成，若本局开启了指引，可按 `G` 打开箭头，再用地图确认楼层。箭头可能先带你去楼梯或门口。
- 无法互动：走近目标，调整视角，确认目标没有被墙、门或界面遮住；手机可以直接点物体可见的部分。
- 断线：保持页面，等待重连提示。短暂离开后尽量回到原设备、原游戏页面。
- 画面或操作不合适：打开游戏设置调整画质、亮度、灵敏度与声音；手机优先保持横屏。
