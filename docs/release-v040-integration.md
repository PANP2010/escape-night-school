# v0.4.0 integration

Release branch: `codex/integrate-v040`, based on deployed `master` `fb7e154`.

The playable registry is now exactly L1, L2, the real third-floor loop, and L4 「广播站」. Completing L3's individual door sequences and gathering advances the existing room to L4. Only stopping L4's broadcast and gathering all surviving players at its third-floor exit completes the current four chapters. The non-production `--l4-preview` entry remains available for isolated acceptance.

Visual polish comes from `881c840` (integrated as `91aec07`), audio/transition polish from `c20e099` (integrated as `d1fcce3`). L4 is an incremental transplant from `codex/loop-l4` `dbeec23`, not a branch replacement. The deployed L3 loop, baritone voice, update-notice lifecycle and `version.json` no-store response are retained. L4 adds two real storeys, numbered shared clues, ordered numeric keypad, natural roll calls, shielding hides and cross-floor monster investigation.

The L3 lifecycle tests retain their independent-player, real aperture, correction-epoch, four-player gathering and fade-freeze assertions, then verify L4's spawn and fresh shared state. The same browser room now progresses L1 → L2 → L3 → L4. L4's standalone browser suite asserts the final four-chapter completion.

Integration fixes include forwarding server errors to the active keypad, capturing spectator Tab cycling while preserving native settings navigation, disposing the L4 voice, and keeping the settings summary clear of the broadcast status. L4 received a wall-backed fallen desk and a hydrant; the unchanged generic collision/containment assertions cover them.

Build-time gzip and Brotli sidecars are negotiated by the static server with encoding, HEAD, cache and freshness coverage. Direct mobile interaction follows actual objects, retains the finger-down target, checks reach and line of sight, and supports holding a fallen teammate to revive. Integration keeps look gestures working over passive HUD panels, consumes the first swipe's dead zone once, clears pending touch actions across level handoffs and gives broadcast objects direct-touch prompts. The L4 landscape browser case physically taps a wall sticker and the console before operating the keypad.

Use `ESC_TEST_PORT=4384` for this worktree's Playwright / L4 runners. Vitest is capped at two workers; browser tests run one worker. Dependencies are a read-only shared symlink and are not committed. Build outputs, browser artifacts and `.green` are local evidence.

The release gate is `ESC_STAGE_GREEN=1 ESC_TEST_PORT=4384 python3 /Users/local-user/escape/loop/parallel_sprint.py gate integration -- npm run check` from `game/`. The L4 preview browser runner uses the same navigation cache generated by the build, avoiding a cold first-room graph build. Separate L4 browser and WebSocket acceptance cover the natural roll-call schedule. Final gate results, exact source commit and SHA-256 manifest accompany the immutable `.green` copy in the deployment handoff; no build is performed after that copy is frozen.
