# 逃离夜校 · 设计文档

午夜的中学，1~4 人合作第一人称逃脱。没有剧情过场，只有关卡、环境叙事碎片（黑板粉笔字、广播、贴纸、作业本）和怪物。尺度：心理恐怖、跳吓、追逐；不展示血肉与尸体（抓到 = 黑屏/罚站），不涉及自杀/自伤、真实政治与真实人物。

## 核心循环
1. 大厅：输入昵称 → 浏览公开房间（房主昵称 +「的教室」、人数 n/4、等待中/第 N 关进行中、往返延迟，每 3 s 刷新），点房间加入或「快速加入」人数最多且未满的等待公开房；没有可用房时自动新建公开房。建房可选公开/私密，仍保留 4 位房间码（字母数字去掉易混的 0/O/1/I）；私密房只允许按码加入，绝不出现在列表。房主点「开始」，中途加入默认以观察者等待下一关；建房时可关闭中途加入，关闭后服务器拒绝进行中的新加入。单人 = 只有自己的房间。
2. 关卡：出生在关卡起点 → 探索、拾取/使用道具、躲避怪物 → 满足出口条件 → 全部存活者进入出口区域 → 结算黑屏 3 s → 下一关。
3. 被抓 = 「罚站」：倒地（视角压低、画面去色、心跳），30 s 内队友对着长按 E 3 s 可救起；超时出局变观察者（自由飞行或跟随队友视角，可打字聊天、可 ping）。
4. 关卡通过时所有观察者复活；全员出局 = 本关重来（同 seed，道具复位）。
5. 通关第 8 关 = 走出校门，显示用时与倒地次数。

操作：WASD 移动，Shift 跑（耐力 6 s，回满 4 s），Ctrl/C 蹲（慢、脚步声小、能钻桌底），F 手电（电量 180 s，电池可拾取），E 交互/救援，鼠标中键或 Q = ping，Enter 聊天，Tab 队伍状态。
速度（m/s）：蹲 1.8 / 走 3.4 / 跑 6.0（耐力满格可连续跑 5 s，4 s 回满）；角色074巡逻 2.0 / 调查 2.9 / 追击 4.6（比走快、比跑慢，耐力耗尽就会被追上）。

声音系统：每个动作产生「噪声」(半径)：蹲 0、走 4 m、跑 12 m、开关门 8 m、撞倒物品 15 m、篮球 10 m。怪物 AI 订阅噪声事件。

## 角色074形象与形态（虚构程序化美术；建模和动作要好）
视觉设计仅使用通用虚构校园巡逻者元素：几何化五官、深色外套、制服配件与夸张轮廓，不引用现实人物、照片或外貌描述。脸部使用程序化 CanvasTexture，无写实皮肤细节、无血腥；形态变化服务于游戏可读性。应用封面和图标另采用无人物的校园门、走廊与警示灯几何图形。
建模：three.js 代码生成 SkinnedMesh（shared 外的 client/src/warden/ 下，纯代码，不依赖外部模型文件），约 20 根骨骼（hips/spine×2/neck/head/肩-上臂-前臂-手×2/大腿-小腿-脚×2/下巴/眼镜挂点），身体 3k–8k 三角，曲面平滑（Lathe/Capsule + 顶点权重），比例准确；衬衫褶皱用法线贴图或明暗贴图。
动作（AnimationClip 关键帧 + 程序化叠加，状态间 crossFade 0.2–0.4 s，步频与移动速度同步、不滑步）：
- 待机：呼吸、推眼镜、背手；巡逻：背着手的老师踱步，偶尔停下左右看；调查：歪头听、俯身看桌底；
- 追击：上身前倾、手臂僵直摆动的快走/小跑（不是正常跑，要怪）；抓到：伸手按肩、指向墙（罚站）；
- 说语录（anim joke）：停住、转头面向玩家、嘴角慢慢上扬、停顿 1 s；后门小窗：只露半张脸，慢慢侧头；
- 头部 look-at 最近玩家（限幅），被盯时眼镜反光。
形态（服务器快照 mob.form 字段，客户端换装/换参数/换动作集，同一套骨骼）：
1. 「班主任」默认：如上，巡逻 2.0 / 追击 4.6。
2. 「变脸」：被盯 2 s 触发；脸贴图切换为过宽的笑、眼镜全白反光，脖子关节瞬间拧到不自然角度后回正，追击时动作更快更抽搐（播放速度 ×1.4、随机帧跳）。
3. 「夜巡」：灰绿毛线帽 + 手里拿手电（真实光锥会扫过走廊），走得慢 1.5 但听觉半径 ×1.5；第 2 关停电层专用。
4. 「点名」：拿着点名册边走边低头念名字（字幕显示真实玩家名），被念到的人 HUD 提示；第 4/8 关。
5. 「满分」终章：身体拉长到 2.3 m、四肢比例变长、走路变成一顿一顿的定格（每 0.3 s 跳一帧），保留虚构制服的轮廓识别点，第 8 关全程追击。
可读性验收：远景剪影一眼认出（虚构制服与反光配件），近景截图正/侧/背/各形态各一张放 docs/shots/warden/，外观由 Claude 自己 Read 截图判断；动作自然度录 10–20 s 视频交给 tools/gemini 看（静态截图看不出滑步/僵硬）。

## 协议（JSON over WebSocket，路径 /ws）
客户端 → 服务器：
- `{t:'hello', name}` · `{t:'create', public?:boolean, allowLateJoin?:boolean}`（旧客户端未给 public 时私密，allowLateJoin 默认 true）· `{t:'join', code}` · `{t:'start'}`（房主）
- `{t:'list'}`：浏览公开房，每连接至少隔 1 s；`{t:'quick'}`：加入人数最多的未满等待公开房，没有则新建公开房。create/quick 每连接共享 1 s 操作冷却，与 list 独立。昵称过滤控制字符、双向覆盖符与尖括号并限 16 字；空房立即隐藏，60 s 后回收，已通关房隐藏并拒绝新加入。
- `{t:'input', seq, p:[x,y,z], yaw, pitch, f}`：20 Hz，客户端本地移动 + 碰撞，服务器校验（最大速度 × 1.3 容差、网格碰撞），不合法则回 `correct`
- `{t:'act', kind:'use'|'pick'|'revive', target}` · `{t:'chat', text}` · `{t:'ping', p}`
服务器 → 客户端：
- `{t:'welcome', id}` · `{t:'room', code, host, started, level, seed, players:[{id,name}], public, allowLateJoin}` · `{t:'error', msg}`
- `{t:'rooms', rooms:[{code,name,n,max,level,state:'waiting'|'playing',allowLateJoin,joinable}]}`：只含非空公开房，max = 4，level 为 0 起始索引；满员或禁止中途加入的进行中房间仍可见但 joinable 为 false。客户端以 list 响应往返时间显示延迟。
- `{t:'snap', tick, players:[{id,p,yaw,st}], mobs:[{id,kind,p,yaw,st}], doors?, items?}`：20 Hz；客户端对他人/怪物做 100 ms 延迟插值
- `{t:'correct', p}` · `{t:'event', kind, ...}`（广播点名、台词 line、倒地、救起、通关）· `{t:'chat', from, text}` · `{t:'ping', from, p}`
flags `f` 位：1 蹲、2 跑、4 手电。`st` 玩家状态：0 正常、1 罚站、2 观察者。

## 性能预算
- 客户端：集显 ≥ 50 fps @ 1080p。draw call ≤ 150（墙/地/天花板按材质合并或 InstancedMesh），三角形 ≤ 150k，动态光 ≤ 2（手电 SpotLight + 1 个环境/应急灯），不开实时阴影（手电除外可选），纹理 ≤ 512²、程序化 CanvasTexture 优先，像素比上限 1.5。只渲染当前关卡；远处雾（FogExp2）裁剪。
- 服务器：20 TPS；单房间 tick ≤ 1 ms（4 人 + 6 怪），10 房间×4 人 CPU < 25% 单核、RSS < 150 MB。快照只发变化的门/道具；位置保留 2 位小数。
- 网络：每客户端下行 ≤ 8 KB/s。
- 生图：全项目 ≤ 25 张（值日生、柜中手、墙面、地砖、黑板、储物柜、门、天花板、logo 等），其余程序化；音效全部 WebAudio 合成。
